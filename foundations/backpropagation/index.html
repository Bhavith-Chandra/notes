Backpropagation

Backpropagation is the chain rule applied in a specific order. That order is the entire contribution: computing derivatives from the output backwards costs about the same as one forward pass regardless of how many parameters there are, while the forward direction would cost one pass per parameter. The price is memory — you must keep every intermediate activation — and that trade determines almost everything about how large models are trained.

What you should walk away with

  • Reverse mode is chosen because networks have one output and many inputs. For f:Rn→Rf: \mathbb{R}^n \to \mathbb{R}f:Rn→R, reverse mode gets the whole gradient in one backward sweep; forward mode needs nnn sweeps. With nnn in the billions this is not a constant-factor difference.
  • The cost is memory, not compute. Every activation on the forward path must be retained for the backward pass. This is why activation memory, not parameter count, usually sets your maximum batch size.
  • Vanishing and exploding gradients are the same phenomenon. Gradients are products of Jacobians along the path; products of many terms either shrink or grow geometrically. Residual connections fix it by making one term of each product exactly the identity.
  • Autodiff is neither symbolic nor numerical. It evaluates exact derivatives numerically by composing known local derivatives — no expression swell, no finite-difference error.
Tier 1 · Intuition

Plain language. No equations, no prerequisites.

Blame assignment

Section titled “Blame assignment”

A network makes a prediction and it is wrong by some amount. Millions of parameters contributed. Which ones, and how much should each move?

The naive approach: nudge one parameter, re-run the whole network, see how the error changed. That is one full forward pass per parameter. For a billion parameters, a billion forward passes per training step. Completely impossible.

Backpropagation gets every parameter’s contribution in a single backward sweep costing roughly what one forward pass costs. That is the whole idea, and it is worth pausing on how large the saving is: a factor of a billion.

How the trick works

Section titled “How the trick works”

Blame flows backwards through the network in the reverse of how the signal flowed forwards.

Start at the output: “the answer was 0.3 too high.” The final layer knows what it did to produce that output, so it can compute two things — how its own weights should change, and how much of the blame belongs to its inputs, which were the previous layer’s outputs.

Hand that blame back one layer. Repeat. Each layer needs only local information: what it received, what it produced, and how much blame arrived from ahead.

The saving comes from sharing. Every path from a parameter to the output goes through the layers ahead of it. Computing blame backwards means each shared segment is computed once and reused by everything behind it, rather than recomputed for every parameter.

Why backwards rather than forwards

You could apply the chain rule from inputs to output instead — that is forward-mode autodiff — and for a function with one input and many outputs it is the better choice. Neural networks are the opposite shape: billions of inputs (parameters), one output (the loss). Match the direction to the shape, and for a scalar loss that means backwards.

The bill: memory

Section titled “The bill: memory”

The backward pass needs to know what each layer saw on the way forward. So every intermediate activation must be kept from the forward pass until the backward pass reaches it.

For a large model with long sequences this dominates memory — often exceeding the parameters and optimizer state combined. It is why you run out of memory when you increase batch size or sequence length, and why gradient checkpointing exists.

Tier 2 · Mechanics

How it actually works. Pseudocode, no heavy maths.

The two sweeps

Section titled “The two sweeps”

Two rules, and the whole algorithm

Section titled “Two rules, and the whole algorithm”

  1. Chain rule along a path. If LLL depends on bbb which depends on aaa, then ∂L∂a=∂L∂b⋅∂b∂a\dfrac{\partial L}{\partial a} = \dfrac{\partial L}{\partial b}\cdot \dfrac{\partial b}{\partial a}∂a∂L​=∂b∂L​⋅∂a∂b​.

  2. Sum over paths. If aaa influences LLL through several routes, add the contributions. This is what makes residual connections and multi-head attention work correctly without special handling.

Everything else is bookkeeping: build the graph during the forward pass, walk it in reverse topological order, and at each node apply the local derivative.

Gradient checkpointing

Section titled “Gradient checkpointing”

The memory/compute dial. Instead of keeping every activation, keep only every n\sqrt{n}n​-th one — the checkpoints — and recompute the rest during the backward pass from the nearest checkpoint.

Memory drops from O(n)O(n)O(n) to O(n)O(\sqrt{n})O(n​) at the cost of roughly one extra forward pass, so about 33% more compute for a large memory saving. Standard practice for training anything that does not fit otherwise.

Vanishing and exploding gradients

Section titled “Vanishing and exploding gradients”

The gradient reaching layer kkk from a network of depth nnn is a product of n−kn - kn−k Jacobians. Products of many terms behave badly:

  • Typical magnitude below 1 → the product shrinks geometrically → early layers get almost no signal.
  • Typical magnitude above 1 → the product grows geometrically → updates explode and training diverges.

These are not two problems. They are the same product behaving in the two ways a product can.

Residual connections are the fix that mattered. Writing y=x+F(x)y = x + F(x)y=x+F(x) makes the Jacobian I+∂F/∂xI + \partial F/\partial xI+∂F/∂x. The identity term means the product contains a 1 at every layer, so there is always a path along which gradient reaches the input undiminished. This is why networks went from tens of layers to hundreds in one paper.

Tier 3 · Formal

The objective, the equations, the guarantees.

Reverse-mode autodiff

Section titled “Reverse-mode autodiff”

Let the computation be a DAG of primitive operations producing intermediates v1,…,vnv_1, \dots, v_nv1​,…,vn​ with vn=Lv_n = Lvn​=L scalar. Define the adjoint

vˉi  ≡  ∂L∂vi.\bar v_i \;\equiv\; \frac{\partial L}{\partial v_i}.vˉi​≡∂vi​∂L​.

Initialise vˉn=1\bar v_n = 1vˉn​=1 and sweep in reverse topological order, accumulating over every consumer jjj of node iii:

vˉi=∑j∈children⁡(i)vˉj ∂vj∂vi.\bar v_i = \sum_{j \in \operatorname{children}(i)} \bar v_j \, \frac{\partial v_j}{\partial v_i}.vˉi​=j∈children(i)∑​vˉj​∂vi​∂vj​​.

The sum is rule 2 above; the product inside is rule 1. Backpropagation is this recursion specialised to a layered network — there is nothing else in it.

Why it costs what it costs

Section titled “Why it costs what it costs”

The cheap gradient principle: for f:Rn→Rmf: \mathbb{R}^n \to \mathbb{R}^mf:Rn→Rm,

forward mode∼O(n)⋅cost⁡(f),reverse mode∼O(m)⋅cost⁡(f).\text{forward mode} \sim O(n) \cdot \operatorname{cost}(f), \qquad \text{reverse mode} \sim O(m) \cdot \operatorname{cost}(f).forward mode∼O(n)⋅cost(f),reverse mode∼O(m)⋅cost(f).

Forward mode propagates one input direction per sweep, giving one column of the Jacobian. Reverse mode propagates one output direction, giving one row.

For a loss, m=1m = 1m=1. So reverse mode delivers the entire gradient in O(1)O(1)O(1) sweeps regardless of nnn. Baydin et al. give the standard bound: the backward pass costs at most a small constant (usually cited as ≤ 4, in practice ≈ 2) times the forward pass.

The memory bound is the other side:

memory=O(number of intermediates on the forward path),\text{memory} = O\big(\text{number of intermediates on the forward path}\big),memory=O(number of intermediates on the forward path),

because reverse mode cannot begin until the forward pass has finished, so every intermediate must survive in between. Forward mode has no such requirement — it needs O(1)O(1)O(1) extra memory — which is the real reason the two modes trade off rather than one dominating.

Layer derivatives

Section titled “Layer derivatives”

For a linear layer y=Wx+by = Wx + by=Wx+b with incoming adjoint yˉ\bar yyˉ​:

Wˉ=yˉ x⊤,bˉ=yˉ,xˉ=W⊤yˉ.\bar W = \bar y\, x^{\top}, \qquad \bar b = \bar y, \qquad \bar x = W^{\top}\bar y .Wˉ=yˉ​x⊤,bˉ=yˉ​,xˉ=W⊤yˉ​.

Three things worth reading off:

  • Wˉ\bar WWˉ is an outer product, so its cost matches the forward matmul.
  • xˉ\bar xxˉ uses W⊤W^{\top}W⊤ — the same weights transposed. This is why the backward pass is often described as running the network “in reverse”.
  • xxx must have been stored. That single requirement is the source of the entire activation-memory problem.

For an elementwise nonlinearity y=σ(x)y = \sigma(x)y=σ(x):

xˉ=yˉ⊙σ′(x).\bar x = \bar y \odot \sigma'(x).xˉ=yˉ​⊙σ′(x).

ReLU’s derivative is 1{x>0}\mathbb{1}\{x > 0\}1{x>0} — exactly 0 or 1. A sigmoid’s peaks at 0.25, so ten sigmoid layers multiply gradient by at most 0.2510≈10−60.25^{10} \approx 10^{-6}0.2510≈10−6. This is the vanishing-gradient problem in one line, and it is why ReLU replaced sigmoid.

Products of Jacobians

Section titled “Products of Jacobians”

For a depth-nnn network,

∂L∂xk=∂L∂xn∏i=kn−1Ji,Ji=∂xi+1∂xi.\frac{\partial L}{\partial x_k} = \frac{\partial L}{\partial x_n} \prod_{i=k}^{n-1} J_i, \qquad J_i = \frac{\partial x_{i+1}}{\partial x_i}.∂xk​∂L​=∂xn​∂L​i=k∏n−1​Ji​,Ji​=∂xi​∂xi+1​​.

Bounding by spectral norms:

∥∂L∂xk∥  ≤  ∥∂L∂xn∥∏i=kn−1∥Ji∥.\left\|\frac{\partial L}{\partial x_k}\right\| \;\leq\; \left\|\frac{\partial L}{\partial x_n}\right\| \prod_{i=k}^{n-1}\|J_i\| .​∂xk​∂L​​≤​∂xn​∂L​​i=k∏n−1​∥Ji​∥.

If ∥Ji∥≤γ\|J_i\| \leq \gamma∥Ji​∥≤γ for all iii, the bound is γ n−k\gamma^{\,n-k}γn−k:

  • γ<1\gamma < 1γ<1: vanishes geometrically.
  • γ>1\gamma > 1γ>1: explodes geometrically.
  • γ=1\gamma = 1γ=1: preserved — and this knife-edge is exactly what normalisation and careful initialisation are trying to hold.

Residual connections. With xi+1=xi+Fi(xi)x_{i+1} = x_i + F_i(x_i)xi+1​=xi​+Fi​(xi​),

Ji=I+∂Fi∂xi  ⟹  ∏i=kn−1Ji=∏i=kn−1(I+∂Fi∂xi).J_i = I + \frac{\partial F_i}{\partial x_i} \implies \prod_{i=k}^{n-1} J_i = \prod_{i=k}^{n-1}\left(I + \frac{\partial F_i}{\partial x_i}\right).Ji​=I+∂xi​∂Fi​​⟹i=k∏n−1​Ji​=i=k∏n−1​(I+∂xi​∂Fi​​).

Expanding the product gives III plus terms involving the ∂Fi\partial F_i∂Fi​. The leading III is a path of length zero from xkx_kxk​ to the loss — gradient reaches every layer undiminished along it, no matter the depth. The network is, in this sense, an ensemble of paths of many lengths, and the short ones carry the gradient.

Gradient clipping

Section titled “Gradient clipping”

Since exploding gradients come from the product’s magnitude, bound it directly:

g←g⋅min⁡(1,c∥g∥2).g \leftarrow g \cdot \min\left(1, \frac{c}{\|g\|_2}\right).g←g⋅min(1,∥g∥2​c​).

Pascanu et al.’s justification is geometric: loss surfaces contain cliffs — regions of sharp curvature where the gradient’s magnitude is enormous but its direction remains informative. Clipping preserves direction and bounds step size, so you step off the cliff carefully rather than being thrown across the landscape.

This is why global-norm clipping is correct and per-parameter value clipping is not: the latter changes the direction, discarding the one thing the gradient still had right.

Checkpointing, formally

Section titled “Checkpointing, formally”

With nnn layers and checkpoints every kkk:

memory=O ⁣(nk+k),\text{memory} = O\!\left(\frac{n}{k} + k\right),memory=O(kn​+k),

storing n/kn/kn/k checkpoints plus the kkk activations of the segment being recomputed. Minimising over kkk:

ddk(nk+k)=−nk2+1=0  ⟹  k=n,\frac{d}{dk}\left(\frac{n}{k} + k\right) = -\frac{n}{k^2} + 1 = 0 \implies k = \sqrt{n},dkd​(kn​+k)=−k2n​+1=0⟹k=n​,

giving O(n)O(\sqrt{n})O(n​) memory for one extra forward pass — the Chen et al. result.

Tier 4 · Frontier

Open problems, current results, and what is still contested.

Where this stands, as of 2026

Section titled “Where this stands, as of 2026”

Backpropagation is not the bottleneck and never really was. The algorithm has been stable since 1986. What changed is the systems engineering around it: mixed-precision training, fused kernels, activation checkpointing, and sharded optimizer state.

Memory is the constraint that shapes distributed training. ZeRO-style sharding partitions optimizer state, gradients, and parameters across devices precisely because backprop’s memory footprint is what limits scale. Tensor and pipeline parallelism are both, at bottom, strategies for fitting the backward pass.

Biological plausibility remains an open question with no practical stakes. Backprop requires symmetric weights for the backward pass and a global error signal, neither of which brains appear to have. Alternatives — feedback alignment, target propagation, forward-forward — are interesting scientifically and none is competitive at scale.

Higher-order information is being revisited. Hessian-vector products via double-backward are cheap enough to be practical, which is what makes the matrix-preconditioner optimizers on the optimization page feasible.

Open problems

Section titled “Open problems”

  • The memory wall is not solved, only managed. Checkpointing, offloading and sharding all trade compute or bandwidth for memory. None removes the underlying requirement that forward activations survive until the backward pass.

  • Sequential dependency limits parallelism. The backward pass cannot start until the forward pass ends, and gradients must flow layer by layer. Pipeline parallelism hides this with micro-batches and cannot eliminate it.

  • No credible alternative learning rule. Every proposed replacement is either much less sample-efficient or has not been demonstrated at scale.

  • Gradient noise is poorly characterised. SGD’s stochasticity is essential to generalisation and there is no good theory of the noise distribution or of what it does — which is the same gap that appears on the generalization page.
