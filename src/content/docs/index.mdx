## What this is

A reference for ML and AI research concepts where every page is written to be
read by someone who has never heard the term *and* by someone who works on it.
That is not a compromise between the two — it is a **layered** page. Tier 1 has no
maths at all. Tier 4 assumes you have read the papers.

You can stop at any tier. The page is designed so that stopping early still
leaves you with something correct, just less complete.

## What this is not

- **Not a tutorial series.** There is no code you run to build a thing. It
  explains; it does not walk you through an implementation.
- **Not comprehensive.** Coverage is deliberately narrow and deep. A page exists
  only when there is something to say beyond what a definition would give you.
- **Not neutral where the evidence is not.** Where a question is genuinely open,
  pages say so and give both sides. Where one position is better supported, pages
  say that instead of hedging.
